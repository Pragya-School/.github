# Pragya Sr Sec School Bhandwa

Welcome to the official GitHub organization of **Pragya Senior Secondary School, Bhandwa**.

## Our Vision

We aim to introduce students to modern technology, programming and collaborative software development using open-source tools.

## What Students Learn

* Programming fundamentals
* Version control with Git
* Collaborative coding
* Project-based learning

## Tools Used

* GitHub Classroom
* Python
* Web Development
* Open Source Projects

## Location

Bhandwa, Haryana, India

We encourage students to explore technology and innovation through real-world coding projects.
